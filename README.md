# Ground Truth ML — Course Material

Public, learner-facing notebooks and supporting files for Ground Truth ML case studies.

- [Gym Marketing](course_material/gym/README.md): four sequential Colab notebooks and the synthetic input tables needed to start EDA.
- [Tourism Recommendation System](course_material/notebook/recommendation_system_in_tourism/README.md): notebooks and instructions for obtaining and preparing the source data. The source data is not hosted here.

Open a Gym notebook in Colab from the case-study website or use the notebook's GitHub page. Read each case README before running its notebooks. Notebooks and data are teaching materials; see the case-specific evidence and license notes.
